# cupongo-api

#  Instructions to launch the application.

# Install dependencies:

```
npm install

```
Modify and add credentials in the .env file

Have a postgres server container installed

In the official docker hub link https://hub.docker.com/_/postgres

Run the command:

```
docker pull postgres
```
3.1 Then run the command

```
docker compose up
```

Once the tables and database have been created and the environment variables have been entered, run the command:

```
npm run dev
```
